## Current stage

**Completed in this project:** research/persona work, CPA-led ad performance review, creative-call integration, Foreplay research, and a proposed 24-concept creative testing plan (9 iterations, 15 net new). **Not started here:** production briefing, assignment, production, and launch. The plan is not by itself proof of client approval, finished briefs, or ads in production.

## Principle

**Research → Persona → Performance → Creative Call → Initial Plan → Foreplay → Revised Plan → Briefing → Production → Launch → Learning.** Maintain one concept ID from research to delivered creative and Meta ad ID. Do not collapse those milestones.

The [upstream Growthub skills](PROCESS.md#1-reuse-canonical-growthub-skills) remain canonical; do not copy them into this client repository. No credentials, private client exports, or ephemeral media CDN URLs should be committed.
